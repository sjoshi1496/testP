# 📝 To-Do List Manager

A simple command-line task manager written in Python. Perfect for learning basic Python concepts like file I/O, JSON handling, and OOP.

## 🚀 Features

- Add tasks with title and optional description
- List all tasks with status and creation date
- Mark tasks as completed
- Delete individual tasks
- Clear all tasks at once
- Persistent storage using JSON file

## 📦 Installation

```bash
git clone https://github.com/yourusername/todo-manager.git
cd todo-manager
python todo_manager.py
